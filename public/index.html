What TaxPilot is

A tax methodology an agent can execute.

TaxPilot gives an AI agent the workflow, tool policy, normalization rules, valuation discipline, FIFO methodology, and output schema required to produce a reviewable report from Binance records.

Not another financial dashboard.

There is no account, upload form, or report builder on this website. The product runs in the user's agent session, where questions can be answered in context and unresolved events can be handled conversationally.

Agent workflow

From one request to a reviewable tax package

The skill defines a six-step process the agent follows in order. Each stage produces an explicit artifact, making the work inspectable and resumable.

  1. 01

    Confirm scope and permission

    The agent confirms the tax year, US jurisdiction, FIFO method, and account scope. It explains exactly what Binance history it will read before making any MCP call.

    CONSENT
  2. 02

    Pull complete Binance history

    Through the user's authenticated Binance Agent OS MCP session, the agent reads spot, deposit, withdrawal, convert, transfer, futures, and margin records. Relevant calls run in parallel.

    READ
  3. 03

    Normalize every source

    Different Binance record shapes become one consistent event stream. Records are categorized, account-scoped, timestamped, and deduplicated before tax treatment begins.

    STRUCTURE
  4. 04

    Value without guessing

    Stablecoin quote values are retained and missing values are derived from available market data. An event that cannot be valued is excluded from totals and placed in the Tax Inbox.

    VALUE
  5. 05

    Compute account-scoped FIFO

    Taxable disposals consume acquisition lots by account. The agent separates short- and long-term gains, ordinary income, non-taxable transfers, and unresolved events.

    COMPUTE
  6. 06

    Explain, resolve, and deliver

    The agent presents the result, confidence level, provenance, and Tax Inbox. User decisions are recorded before the final Form 8949 rows and audit package are produced.

    DELIVER

Agent output

A result with its reasoning attached

TaxPilot does not reduce a year of account activity to an unexplained number. The result remains connected to source records, lot matching, valuation provenance, and user decisions.

01

Capital result

Proceeds, cost basis, gains, losses, and short- versus long-term treatment.

02

Form 8949 rows

Structured disposal records with acquisition date, disposal date, proceeds, basis, and gain or loss.

03

Ordinary income

Rewards, staking, airdrops, and other identifiable income presented separately.

04

Tax Inbox

Missing basis, uncertain ownership, unsupported records, and unavailable valuations requiring input.

05

Confidence

A resolved-event ratio that reaches 100% only when no event remains unresolved.

06

Audit package

A structured record of normalized events, calculation outputs, provenance, and decisions.

Built-in guardrails

Strict boundaries are part of the product

READ

Only approved history tools

The skill restricts the agent to an explicit allowlist of Binance history and market-data tools.

BLOCK

No financial actions

Trade, transfer, withdrawal, borrow, order, create, cancel, and other write operations are forbidden.

REVIEW

No invented tax facts

Missing valuations and uncertain transfer ownership become explicit questions instead of silent assumptions.

SCOPE

No filing or tax advice

TaxPilot performs a mechanical calculation. A licensed professional should review the result before filing.
